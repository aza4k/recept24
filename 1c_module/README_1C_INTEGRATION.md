# 🔄 Recept24 — 1C:Предприятие 8.3 Интеграция Қўлланмаси

Ушбу қўлланма 1С дастурчилари ва дорихона маъмурлари учун Recept24 платформаси билан автоматик нарх ва қолдиқларни улаш бўйича тайёрланган.

---

## 1. Ишлаш принципи
Ҳар бир дорихонага Recept24 платформасидан махсус **API Key** (масалан: `rec_a1b2c3d4...`) берилади.
1С дастури ҳар 10-15 дақиқада фон режимида қолдиқлар рўйхатини олиб, HTTPS POST орқали Recept24 серверига жўнатади.

```
[1C:Аптека / 1С:Розница] 
       │ 
       ▼ (HTTPS POST JSON, header: X-Pharmacy-Key)
[Recept24 Markaziy API: /api/sync/1c/]
       │
       ▼ (Shtrix-kod / Nom bo'yicha moslash)
[Narxlar va Qoldiqlar Yangilandi] ──► [Recept24 Mobil Ilovasi]
```

---

## 2. 1С да улаш босқичлари

### 1-Қадам: API Key олиш
Дорихона раҳбари Recept24 Desktop (компьютер) дастурига кириб, **"1C ва Эксел созламалари"** бўлимидан ўз дорихонасининг **API Key** калитини нусхалаб олади.

### 2-Қадам: 1С га Модулни ўрнатиш
1. `Recept24_Sync_1C.bsl` файлини очасиз.
2. 8-қатордаги `ApiKey` ўзгарувчисига дорихона калитини ёзасиз:
   ```bsl
   ApiKey = "rec_SIZNING_DORIXONA_KALITINGIZ";
   ```
3. Ушбу процедурани 1С да:
   - **Вариант А:** Ташқи ишлов берувчи (Внешняя обработка `.epf`) шаклидаги "Синхронизация" тугмасига улаш;
   - **Вариант Б (Тавсия этилади):** 1С Регламентное задание (Фоновое задание)га қўшиб, ҳар 15 дақиқада автоматик ишлайдиган қилиб созлаш.

---

## 3. Юбориладиган JSON формати

```json
{
  "items": [
    {
      "barcode": "4780012340001",
      "name": "Парацетамол 500мг №10",
      "price": 2500.0,
      "quantity": 120,
      "in_stock": true
    },
    {
      "barcode": "4011548001234",
      "name": "Мезим форте №20",
      "price": 34000.0,
      "quantity": 15,
      "in_stock": true
    }
  ]
}
```

### Майдонлар тавсифи:
- `barcode` *(string)*: Дори қутисидаги штрих-код (EAN-13). Энг муҳим майдон — дорини базада 100% аниқ топиш учун ишлатилади.
- `name` *(string)*: Дорихона 1С идаги номланиши.
- `price` *(float)*: Дорихонадаги сотилиш нархи (сўмда).
- `quantity` *(int)*: Қолдиқ сони.
- `in_stock` *(bool)*: Мавжудлиги (`true` ёки `false`).

---

## 4. Сервер жавоблари
- **200 OK:** Муваффақиятли қабул қилинди:
  ```json
  {
    "status": "success",
    "pharmacy": "Шаңарақ дәриханасы",
    "items_received": 50,
    "items_updated": 48,
    "new_medicines_added": 2,
    "errors_count": 0
  }
  ```
- **401 Unauthorized:** API Key нотўғри ёки фаол эмас.
- **400 Bad Request:** JSON формат хато.
